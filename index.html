03 Réalisation phare

Exploitation d'un buffer overflow → root

Skills Assessment HackTheBox Academy — Stack-Based Buffer Overflows on Linux x86. D'un simple accès utilisateur à un shell root, avec write-up complet à l'appui.

● Criticité : Critique ✓ Résolu — uid=0 Boîte grise · Linux x86 32-bit

NIXBOF32 — élévation de privilèges par dépassement de tampon

À partir d'un accès SSH utilisateur non privilégié, exploitation d'un binaire SUID root vulnérable (strcpy() non borné sur argv[1]) pour exécuter du code arbitraire et lire /root/flag.txt.

Vecteur
Binaire SUID root
Offset retour
2060 octets
Technique
NOP sled + shellcode
Résultat
root + flag

Démarche

  1. Énumération locale et inventaire des binaires SUID (find / -perm -4000).
  2. Analyse statique du binaire : file, readelf -l, désassemblage objdump.
  3. Analyse dynamique sous gdb pour localiser le tampon et confirmer l'offset.
  4. Constat : protections mémoire toutes absentes (ASLR off, pile RWE, pas de canary).
  5. Construction d'un payload NOP sled + shellcode execve null-free, puis bruteforce de l'adresse de retour sans octet nul.
  6. Shell root obtenu, lecture du flag, rédaction du rapport.

Compétences démontrées

  • Exploitation bas niveau : pile, registres, assembleur x86.
  • Shellcoding et contrainte des octets nuls via argv.
  • Lecture des protections mémoire (ASLR, NX, canary, PIE).
  • Rédaction d'un rapport : synthèse, finding, reproduction, impact, remédiation.
